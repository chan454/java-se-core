# java-se-core

Java SE 核心内功、数据结构与算法、并发编程（JUC）及 JVM 底层原理实战练习仓。

## 🛠 开发环境与规范

- **JDK 版本**：JDK 21 / 25
- **开发工具**：IntelliJ IDEA (macOS)
- **包命名规范**：`com.chancode.<专题>`
- **提交规范**：遵循 Conventional Commits（`feat` / `fix` / `refactor` / `docs`）

## 📂 模块规划与进度

| 模块目录             | 核心专题                                  | 状态     |
|:-----------------|:--------------------------------------|:-------|
| `m01-algorithm`  | 常见排序、查找与基础算法思想                        | 🚀 进行中 |
| `m02-collection` | Collection / List / Set / Map 源码与底层结构 | ⏳ 待开启  |
| `m03-io-stream`  | 字节流、字符流、缓冲流与 NIO 基础                   | ⏳ 待开启  |
| `m04-thread-net` | 多线程基础、线程池与 Socket 网络编程                | ⏳ 待开启  |
| `m05-juc`        | JMM 内存模型、锁机制、CAS 与并发容器                | ⏳ 待开启  |
| `m06-jvm`        | 类加载机制、运行时数据区与 GC 调优                   | ⏳ 待开启  |
