# java-se-core

Java SE 核心内功、数据结构与算法、并发编程（JUC）及 JVM 底层原理实战练习仓。

## 🛠 开发环境与规范

- **JDK 版本**：JDK 21 / 25
- **开发工具**：IntelliJ IDEA (macOS)
- **包命名规范**：`com.chancode.<专题>`
- **提交规范**：遵循 Conventional Commits（`feat` / `fix` / `refactor` / `docs`）
